# PCF_project

Python computations and Lean formal proofs for PCF research.

- [python_implement/](python_implement/README.md): Python implementation, examples, tests, documentation and references.
- [lean/secant-induction/](lean/secant-induction/README.md): Lean proof project and verification reports.

Open `PCF_project.code-workspace` in VS Code to work on both projects.
Run Python commands from `python_implement/` and Lake commands from
`lean/secant-induction/`. Run Git commands from the repository root.

See [the workspace guide](python_implement/docs/WORKSPACE.md) for more details.
